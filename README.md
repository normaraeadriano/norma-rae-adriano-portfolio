# Norma Rae Adriano — Portfolio Website

This folder is prepared for publishing with GitHub Pages.

## Files
- `index.html` — complete, self-contained portfolio website (CSS, JavaScript, and embedded resume/certificate assets are included).
- `.nojekyll` — tells GitHub Pages to serve the static files without running Jekyll processing.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `norma-rae-adriano.github.io` only if your GitHub username is `norma-rae-adriano`. Otherwise, for a project site, choose a repository name such as `norma-rae-adriano-portfolio`.
2. Open the new repository and choose **Add file → Upload files**.
3. Extract this ZIP on your computer first. Upload the *contents* of this folder (`index.html`, `.nojekyll`, and `README.md`) into the repository root—not the ZIP file itself and not an extra enclosing folder.
4. Click **Commit changes**.
5. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**. Select branch `main` and folder `/(root)`, then save.
6. Wait for the deployment to finish. Under **Settings → Pages**, use **Visit site** to open the published URL. It may take several minutes for the first deployment.

## Expected URL format
- User site (repository name exactly `<your-github-username>.github.io`): `https://<your-github-username>.github.io/`
- Project site (any other repository name): `https://<your-github-username>.github.io/<repository-name>/`

Replace the placeholders with your actual GitHub username and repository name. The URL is not live until you complete the publishing steps.

## Before publishing
This portfolio includes public contact details and a resume download. Review the page and resume to make sure you are comfortable making those details public. Never upload passwords, identity documents, or other sensitive/private files.
